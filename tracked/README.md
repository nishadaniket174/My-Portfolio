# Aniket Kumar Nishad - Technical Portfolio

Live Portfolio: [https://my-portfolio-tracked.vercel.app/](https://my-portfolio-tracked.vercel.app/)  
GitHub Profile: [https://github.com/nishadaniket174](https://github.com/nishadaniket174)

Tactical HUD-inspired developer portfolio designed for a computer science undergraduate specializing in Artificial Intelligence and Machine Learning at Newton School of Technology, Pune.

## Application Architecture
- **Root Directory:** `tracked/`
- **Data Source of Truth:** `tracked/src/data/site.ts`
- **Core Sections:**
  - **Hero:** Student developer identity, mission statement, and tactical HUD telemetry.
  - **About:** Educational focus, academic year, and career aspirations.
  - **Skills & Proof of Work:** Grounded skill taxonomy and live interactive tools (**LLM Playground** and **Token Explorer**).
  - **Open-Source Contributions:** 10 regression testing and mathematical validation pull requests to `S-AI-Projects / TheAlgorithms-JavaScript`.
  - **Technical Projects:** Deep technical breakdowns (Problem Statement, Solution Architecture, Tech Stack, Individual Contribution, Repository & Live Demo) featuring **Weekwise** and **LLM Playground**.
  - **Let's Connect:** Direct communication channels (GitHub, LinkedIn, verified Email).
  - **System Settings:** High-Visibility Lab theme toggle and 4-tier accessible typography scaling.
